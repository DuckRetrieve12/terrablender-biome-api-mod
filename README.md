# TerraBlender — Biome API for Mods

[![Download Latest](https://img.shields.io/github/v/release/DuckRetrieve12/terrablender-biome-api-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/DuckRetrieve12/terrablender-biome-api-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

An API for Forge and Fabric allowing mods to add custom biomes without conflicting with each other.

![TerraBlender — Biome API for Mods Preview](https://cdn.modrinth.com/data/kkmrDlKT/ffe690c604b123c63ee77a5baf76cf008cb73663.png)

## Features

- Region-based biome placement without conflicts
- Mods add biomes to their own private region
- Compatible with Terralith, BYG, and all biome mods
- Supports unique Nether biome region injection
- The standard biome API used by all major biome mods

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your Minecraft version
2. Download the JAR matching your exact Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** See download table above
